版本 V1.2；日期 2026-10-24（Asia/Shanghai）；包 XJ-UI-FULL-20261024-V1.2；状态：已按实际UA1验收，作为当前设计系统。

依据：[当前有效决策](../../03-架构/决策/当前有效决策.md)、[当前资料清单](../../03-架构/评审/当前资料清单.json)。当前设计以原高保真首页的布局、适度圆角及顶部/内容比例为依据，并结合补充截图完成。支持矩阵与反馈预算随UI V1.2接受，当前进入阶段3；业务仍全部模拟。

## 1. 视觉、品牌与资源

前台用完整封面、独立深色介绍栏和圆角白色作品列表建立阅读气氛；正文和标题采用现有中文无衬线以减轻尖锐感。后台用深色圆角侧栏、浅色主区、横向表格、字段分组及来源记录完成任务。没有重新命名、重绘 Logo 或安装字体。

原 Logo 来源：[原 HTML](../../01-产品专家/游戏平台高保真.html)；提取证据：[来源记录](../sources/logo-extraction-20261024.json)。文字为“间隙 PLAY”，间隙 #24252b，PLAY #df5a4e，23px/800/letter-spacing:-.05em；小于等于440px为20px。使用原字体栈 `-apple-system,BlinkMacSystemFont,"Segoe UI","PingFang SC",sans-serif`。两端共用，不将游戏封面当 Logo。四周至少留8px，不能拉伸、换字、改色或压在复杂图片上；此留白是本轮用法提案。

概念封面：[telephone-concept.png](../assets/concepts/telephone-concept.png)，1536×1024，约1.7MB，原创生成资产的沿用副本；[来源与限制](../sources/concept-art-provenance-20261024.md)。不是游戏实机、商用权利审核结果或完整游戏资源。G-B使用文字占位，不拷贝鬼媒婆画面。

封面槽位3:2，建议源1536×1024；本轮首页主推荐保留完整封面（contain），不得以裁切填满替代整图。每作1封面、0–8截图，截图保留自身比例并有替代文本；无截图时不造实机图。封面读取失败有文字替代。正式编码、压缩、体积与分发方案后续架构确定；当前PNG尚未作上线优化。

圆角使用12px主推/运行外壳、10px内容/后台分区、7px按钮/提示/字段。导航使用文字及当前页下划线。深色栏使用#25252c、白色正文和#d5d3d9辅助文字。Logo在后台深色栏内置于浅色承载区，原字形与颜色完全保留。封面按3:2等比完整展示，不再以文字覆盖的渐变裁切作首页主推；手机先封面再介绍，列表在440px以下改纵向整图。

## 3. 组件与状态

| 组件 | 默认与交互 | 异常和可访问要求 |
| --- | --- | --- |
| 导航/面包屑 | 当前页文字及下划线；链接有明确文本 | 键盘焦点3px；窄屏换行，不只靠颜色 |
| 主次按钮 | 主操作深珊瑚/白字；次操作白底；最小高度44px | hover更深、disabled原生禁用；不以禁用替代问题说明 |
| 字段 | 可见标签、约束说明、保留输入 | 校验错误role=alert，不静默裁剪Unicode内容 |
| 搜索/筛选 | 关键词与玩法条件可清除、分享、返回保留 | 空结果给清除出口；固定排序和单页说明，不造排名 |
| 作品行/详情 | 展示设备、语言、试玩、范围、提供方、版本、内容提示 | 缺图/未知时长/暂停/停售分别说明 |
| 购买核对 | 账号、范围快照、目标价、来源、抵扣、应补和勾选 | 过期/变化/来源退款待查不能直接提交；重核后再次确认 |
| 现金/权益/运行摘要 | 分列说明，各自可查证 | 未知不等于失败，付款不等于交付，保存不等于购买 |
| 状态提示/空态 | 文字、原因、下一操作；live区域反馈 | 读取失败可重试/返回/支持，不造百分比或到达时间 |
| 表格 | 标题、列头、数值、来源、状态 | 窄屏表格自身横向查看；整页不横向滚动 |
| 确认表单 | 先说明范围/影响、明确勾选、可取消 | 重开/恢复不影响其他游戏与购买；破坏性注销另有分步 |
| 存档来源选择 | 当前档+上一恢复点，冲突保留双方 | 第三来源暂缓、超1MiB拒写、不兼容保留来源，不假报同步 |
| 平台运行外壳 | 返回、帮助、加载阶段、静音/扩大 | 中央游戏区域占位；无剧情、引擎、真实容器或声音 |

加载、无数据、错误、无权限、身份失效为通用模板；作品、订单、售后等使用各自业务状态。具体255个状态见[路由清单](../sources/page-state-inventory-refined-v1.2.json)，相同模板复用不等于255张独立视觉稿。

## 4. 文案与业务规则呈现

游客试玩主按钮“无需登录，免费试玩”；购买前才出现登录验证。导入可跳过，不能把进度当权益。无真实账号/邮件/口令：只使用readonly的`.invalid`演示邮箱和禁用密码输入。

V0.1买断/G-A；V0.2章节/G-B/差价；V0.3场景及回归。在同一个设计演示中可查看后续版本，不能据此声明首版实现。场景/章节是游戏侧内容标识，不按页面/链接计费，也不让平台接管剧情。

升级展示同账号、同作品、同币种的合格来源；来源净实付只抵一次，最多抵目标价。零补款不接渠道、不返现。升级退款默认仅新增现金和升级授予，原有效来源保持。普通停售与安全暂停区别显示。

注销按重新识别→影响与二次确认→申请/人工处理→玩家最终不可逆确认；最终前可撤回，最终后立即停止访问。分类清理展示7日在线目标、30日隔离备份轮转，以及必要交易/售后受限保留与超期查证，不承诺设备远程全删。人工48小时首回/72小时更新/7日方案或查证/>30日复核、计划永久终止至少60日通知均为产品既定目标，不是当前已具备运营能力。

## 6. 加载与反馈预算提案

本节为已接受的UI反馈目标，不是已测性能、后端超时或新的付款失败规则：

- 本地交互希望100ms内给出可见反馈，提交后先保留输入和操作语境。
- 超过1秒显示实际等待阶段；未知总量不显示虚假百分比。
- 等待超过10秒提供查询、重试或支持出口；不得仅凭时间判定付款/退款/启动失败。
- 首页只展示商店素材，不预载完整游戏包；真实资源预算由后续架构和开发实测收敛。

## 7. 移交、修改和验收

HTML/CSS/JS为可编辑设计源，不代表生产业务已实现；没有Figma源文件。设计全包已按实际UA1接受，修改已验收方向或产品规则须记录影响再确认。UI验收不会自动批准技术方案、购买资源、开发游戏或上线。

当前进行阶段3架构：现有系统复用、可信身份/权益、存档、事件、版本、隔离、故障和生命周期方案。UI的占位布局不能替代架构决策，已选方向见当前有效决策。
