## 启动

从项目根目录执行：

```sh
python3 -m http.server 8768 --bind 127.0.0.1 --directory docs/03-design
```

浏览器打开 `http://127.0.0.1:8768/demos/platform-demo-refined/`。当前会话已启动此本地预览；这不是外网发布或生产部署。若端口占用，复用已启动服务，或选另一端口。

无需依赖安装、业务服务、数据库或凭据。源文件为index.html、tokens.css、styles.css及data/front/admin/app.js；相对引用现有概念图。

## 查看方式

顶部“查看页面”“模拟状态”“演示身份”仅为评审控制，不属于最终产品导航。31路由、255个可选页面状态；同模板复用。身份可切游客、已登录未验证、已验证、注销申请中。访问私人页前用演示身份切换或沿模拟登录路径进入。地址中的state/game/q/filter仅为设计预览条件，不是可信授权依据。

主要入口：`#/store`、`#/detail`、`#/checkout?state=credit`、`#/saves?state=conflict`、`#/deletion`、`#/ops/games`、`#/ops/publish?state=blocked`、`#/ops/finance?state=negative`、`#/components`。

## 建议评审顺序

1. 重置演示，从首页“免费试玩”进入平台外壳，查看付费边界。没有加载真实游戏。
2. 从边界购买，模拟登录、模拟邮箱验证。选择导入或跳过；返回原作品核对范围及价格。
3. 勾选确认后下单，先到“付款待核实”。第一次模拟查询仅确认收款，第二次模拟查询才交付权益；随后进入外壳。
4. 查看另一作品，已购状态不跨作品转移。已有范围再次购买返回已有来源，不重复下单。
5. 演示身份设为已验证，查看免费领取、零补款、章节抵扣和场景页面；后续版本有显式标记。
6. 查看云档冲突、第三来源、超限、兼容失败、恢复和重开确认；全部不读写真实进度。
7. 注销重新识别后确认影响，先申请可撤回，再查看玩家最终确认及分类清理/超期反馈。
8. 后台查看作品→版本接入→商品范围→审核发布；缺项时提交仍阻止。再查看订单、售后、金额、分析、账号清理及恢复反馈。

买断28元、章节来源10元、应补18元仅为纸面样例，非已定商业售价。金额页面包括免费、零补款不重复记现金；费用未知时暂计；跨期退款可出现负净收。统计不填造业务KPI。
