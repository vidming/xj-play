# 独立前端游戏能力与可信边界核查

- **状态：阶段 1 产品候选资料；仅说明能力与可信边界，不代表需求或实现方案已批准。**
- 研究日期：**2026-10-24，Asia/Shanghai（UTC+08:00）**。下列访问时刻是实际抓取时间，不是页面发布日期。
- 范围：浏览器玩法、身份与付费访问、已交付内容保护、本地与云存档。以 OWASP Authorization 和 MDN Web Storage 为主，iframe 与第三方支付资料仅作补证。
- 方法：`web.run` 尝试未返回可用正文，随后使用 Python `urllib` 对四个官方页面执行只读访问，核对正文并记录 HTTP 状态、HTML 标题、最终 URL 和 UTC 时刻。未登录，未运行游戏，未进行身份、支付、存档或安全测试；未写入凭据。

## 简明结论与来源

| 编号 | 结论 | 证据与限制 |
| --- | --- | --- |
| C01 | **能力判断：独立前端游戏的交互玩法可以由浏览器承载。** HTML 文档、脚本执行与浏览器存储提供了交互和本地状态的基础；若采用嵌入展示，iframe 可以容纳另一个文档。 | [S2：Web Storage](https://developer.mozilla.org/en-US/docs/Web/API/Web_Storage_API)、[S3：iframe](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/iframe)。这是能力层面的归纳，不是对任意游戏、性能、移动端兼容性或离线能力的实测承诺，也不构成采用 iframe 的决定。 |
| C02 | **明确原则：身份认证与授权不同，登录不等于已购买，也不等于可以访问任意内容。** 前端显示的“当前用户”“已登录”“已解锁”，不能独自证明真实账号归属或访问权益。 | [S1：Introduction；Verify that Authorization Checks are Performed in the Right Location](https://cheatsheetseries.owasp.org/cheatsheets/Authorization_Cheat_Sheet.html)。OWASP 明确区分认证与授权，并禁止把客户端检查作为访问裁决的决定因素。这里的“身份”指账号身份；不涉及法定实名或 KYC 认证。来源没有核查具体身份产品。 |
| C03 | **明确原则：付费访问不能仅信任前端。** 隐藏入口、前端变量或本地“已付款”标记可以影响展示，但不能作为受保护资源的最终授权依据；静态文件也属于访问控制范围。 | [S1：Validate the Permissions on Every Request；Enforce Authorization Checks on Static Resources；Verify that Authorization Checks are Performed in the Right Location](https://cheatsheetseries.owasp.org/cheatsheets/Authorization_Cheat_Sheet.html)。应由浏览器外的可信控制方裁定受保护访问；此处不指定技术或部署方式。 |
| C04 | **明确原则：支付成功页面和浏览器回跳参数不能单独证明支付完成。** OWASP 要求在履约前由可信侧核验支付状态，并核对订单、金额、币种及通知真实性。 | [S4：What Can Go Wrong at Each Step and How to Prevent It，尤其第 2 项](https://cheatsheetseries.owasp.org/cheatsheets/Third_Party_Payment_Gateway_Integration_Cheat_Sheet.html)。这是通用安全指导，不证明任何具体渠道已接通、账户可收款或真实交易成功，也不把任意服务间通知一概当作可信。 |
| C05 | **分析推断：控制内容交付，不等于让已交付内容绝对不可复制。** 若完整代码、素材或章节数据已经下发，且能由浏览器独立使用，不能仅凭隐藏界面、脚本内的解锁判断或 iframe，承诺这些内容不可提取、留存或在本地绕过限制。撤销后续访问也不能据此承诺撤回已交付副本。 | 依据 [S1：客户端逻辑可绕过、静态资源应受授权控制](https://cheatsheetseries.owasp.org/cheatsheets/Authorization_Cheat_Sheet.html)，结合 [S3：iframe 的嵌入与隔离职责](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/iframe)。这是限定于已下发、浏览器可独立使用内容的产品边界推断；来源没有评估 DRM，也不证明所有保护措施均无效。 |
| C06 | **明确事实：本地存档与账号云存档是不同能力。** `sessionStorage` 按来源和标签页划分，关闭标签页会清除；`localStorage` 按来源划分，通常可在关闭并重开浏览器后保留。Web Storage 提供浏览器本地键值存取，不能据此宣称已有跨设备同步或账号云恢复。 | [S2：Concepts and usage；Private Browsing / Incognito modes](https://developer.mozilla.org/en-US/docs/Web/API/Web_Storage_API)。隐私模式下的本地数据会随相应隐私窗口或标签关闭而清除。持久化不等于永久保存或备份保证；本文的本地存档讨论限于 Web Storage。 |
| C07 | **明确事实与推断：嵌入不会自动打通宿主页账号、权益和存档。** iframe 中的存储与该文档来源有关；同源策略、sandbox 和浏览器隐私设置会影响访问。由此不能把嵌入成功等同于获得平台身份、支付凭据或云存档。 | [S2：Determining storage access by a third party](https://developer.mozilla.org/en-US/docs/Web/API/Web_Storage_API)、[S3：sandbox；Scripting](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/iframe)。MDN 还提示禁用第三方 Cookie 时第三方 iframe 的 Web Storage 访问可能受阻；具体浏览器、嵌入上下文和设置仍需另行验证。 |

## 前端与平台的产品边界

以下可信控制方指浏览器外负责核验业务事实的平台服务或其可信依赖；项目建设游戏商店平台的目标已明确。**这不表示已经决定自行实现所有底层服务，也不构成架构或接口设计。**

| 事项 | 独立前端可承担的候选职责 | 不能据此前端行为认定的事实 |
| --- | --- | --- |
| 玩法与展示 | 输入响应、规则执行、画面和音效、本地进度展示。 | 玩法可以运行，不证明账号、付费门禁或防复制已成立。[S2](https://developer.mozilla.org/en-US/docs/Web/API/Web_Storage_API)、[S3](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/iframe)、[S1](https://cheatsheetseries.owasp.org/cheatsheets/Authorization_Cheat_Sheet.html) |
| 身份与权益 | 展示经确认的账号和权益状态。 | 前端自行声明身份、本地解锁状态不能替代可信方的认证结果和授权裁定；两者须分别理解。[S1](https://cheatsheetseries.owasp.org/cheatsheets/Authorization_Cheat_Sheet.html) |
| 支付与交付 | 展示付款入口、跳转过程和结果提示。 | 页面跳转成功不等于到账或权益生效；支付事实及据此授予访问属于可信业务边界。[S4](https://cheatsheetseries.owasp.org/cheatsheets/Third_Party_Payment_Gateway_Integration_Cheat_Sheet.html)、[S1](https://cheatsheetseries.owasp.org/cheatsheets/Authorization_Cheat_Sheet.html) |
| 本地与云存档 | 保存和读取当前浏览器可访问的本地进度。 | 本地存储不自动成为账号云存档。若产品主张跨设备找回，需另有可核验的远端保存、身份归属及同步能力；是否提供尚未决定。这是从本地存储范围作出的产品推断。[S2](https://developer.mozilla.org/en-US/docs/Web/API/Web_Storage_API)、[S1](https://cheatsheetseries.owasp.org/cheatsheets/Authorization_Cheat_Sheet.html) |
| 内容保护 | 展示已获得的内容、呈现访问提示。 | 可信方控制受保护内容后续交付，与已下发副本的保护是两个问题；不能把前者宣传为后者的绝对保证。此项沿用 C05 的限定推断。[S1](https://cheatsheetseries.owasp.org/cheatsheets/Authorization_Cheat_Sheet.html)、[S3](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/iframe) |

### 支持段落及各源限制

- **S1 Authorization：** `Introduction` 区分认证和授权；`Validate the Permissions on Every Request`、`Enforce Authorization Checks on Static Resources`、`Verify that Authorization Checks are Performed in the Right Location` 支持 C02、C03，并为 C05 提供推断基础。它是 OWASP 官方项目的通用安全指导，不是本项目安全审计、身份实现证明或付费产品认证。
- **S2 Web Storage：** `Concepts and usage`、`Determining storage access by a third party`、`Private Browsing / Incognito modes` 支持本地存储生命周期、来源边界及隐私模式限制。MDN 是浏览器技术文档，不能替代特定浏览器和嵌入环境的兼容性验证；该页没有定义本项目的云存档服务、永久保留政策或跨设备同步保证。
- **S3 iframe：** 开头定义嵌套浏览上下文；`sandbox` 和 `Scripting` 说明脚本、来源及隔离约束。它证明的是嵌入与浏览器隔离语义，没有承诺账号打通、支付验证、反复制或项目可用性，也不是要求采用 iframe。
- **S4 第三方支付：** `Understanding the Payment Flow` 与 `What Can Go Wrong at Each Step and How to Prevent It` 支持支付回跳不可信、可信侧核验及订单要素比对。该资料是 OWASP 的通用集成指导，并非任何具体支付渠道的官方契约、地区准入说明或真实支付测试。
