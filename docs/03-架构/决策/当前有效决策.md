## 产品与设计

- 品牌为“间隙PLAY”；原高保真 HTML 是 Logo 来源。保留原 Logo，玩法和商店展示只是案例。
- 平台负责发现、身份、交易、权益、运行接入、约定存档与事件、后台运营；独立游戏负责内容、玩法、页面、框架及专有数据。平台不强制统一剧情引擎。
- 实际 PR1 已接受产品 V1.0；实际 UA1 已接受 UI V1.2。UI Demo 全部业务模拟，视觉验收不证明真实登录、付款、权益、存档、游戏或部署。
- 游客直接试玩；购买、完整免费领取、私人云档或导入前验证身份及邮箱。进度不授予权益。
- V0.1 买断与 G-A，V0.2 章节、G-B 和差价升级，V0.3 场景与回归验证。三类收费通过游戏自有 contentKey 映射，重进、链接跳转不额外收费。
- 完整原创双游戏在平台之后按独立工程设计、开发并真实接入；当前尚未制作，测试接入样例不能代替完整作品。
- UP1、RF1、SS1、AD1、FS1、DP1、SV1 沿用当前产品规格。详细金额、存档、删除、数据保留和售后规则以当前产品文档为准，不因资料整理改动。
