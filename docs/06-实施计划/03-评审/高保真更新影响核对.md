## 4. 已验证问题及质量边界

- **P1：品牌规范漂移。** `store.css:4`将首页Logo字号覆盖为29px，1200px断点下为25px；实测与声明一致。既有尺寸规范为23px/20px。推荐保持原标识与已确认规范，不自行重设计。
- **P2：小型操作目标。** 三档视口下“清除”高度约21.44px、卡片“免费试玩”22px。建议扩大有效点击区域，手机回归需核间距、触摸及焦点；不能仅凭高度断言所有目标均违反WCAG例外条款。
- **P2：证据与名称未同步。** 首页布局已变，但演示栏仍称原稿比例修订版V1.2；旧验收数据不足以证明本次首页。需在新确认后替换当前记录。
- **P2：低对比风险待测。** 辅助文本多用`#888/#999`、11–12px字号。当前未完成逐元素背景合成与对比率测量，不报告为已证实的全站WCAG失败。

Impeccable机械检测实际执行一次，返回2项warning与1项advisory：彩色阴影、径向光晕、重复条纹。人工核对这些主要位于CSS概念封面，属于封面插画表现，不能据此推断平台页面整体采用暗色背景或存在功能缺陷；本轮不将其列为必须删除项。性能、主题和无障碍未做完整量化审计，不编造总评分。

积极结果：占位内容明确标注、无虚构上架入口；筛选与排序使用原生按钮及`aria-pressed`；结果计数有状态语义；概念封面与实机内容区分；新增封面未引入远程素材依赖。
